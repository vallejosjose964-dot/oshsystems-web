What is OSH

A different paradigm.

OSH — Homeostatic Semantic Organism — is a proposed cognitive architecture in which the active computational object is a continuously regulated endogenous state and its trajectory through structured state space.

“Organism” is an architectural term for persistent internal regulation and coordinated functional subsystems. It is not a biological-life claim.

From PC to microcontrollers

Same architectural direction. Real hardware.

The compact embedded OSH C substrate passed cross-target compilation across unrelated embedded instruction-set families. Physical execution in the current public evidence is demonstrated on two ESP32-S3 devices.

ARM Cortex-M, RISC-V, AVR and MIPS32 are compiler-level portability results. They are not presented as physical-board execution claims.
